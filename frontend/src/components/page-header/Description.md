# Page Header

## Назначение

Единая горизонтальная область интерфейса KSC, расположенная сразу под
верхней границей основной рабочей области.

### Содержит

- название страницы;
- краткое описание;
- выбор периода для мониторинговых страниц;
- выбор интервала автообновления;
- ручное обновление.

### Режимы

`monitoring` — период, автообновление и кнопка обновления.

`default` — только название и описание.

## Период

Поддерживаются относительные диапазоны и абсолютный диапазон даты/времени.
Контракт `TimeRange` подготовлен для будущего подключения долговременного
источника исторических метрик.

## Анимация

Во время загрузки страницы или обновления данных нижняя линия шапки получает
плавную небесно-голубую волну. Постоянной анимации нет.
