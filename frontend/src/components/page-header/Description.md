# Глобальная шапка страницы KSC

## Назначение

Папка содержит единый горизонтальный заголовок страниц Kafka System Control.

## Состав

- `PageHeader.tsx` — общая горизонтальная область страницы;
- `TimeRangePicker.tsx` — выбор относительного или абсолютного периода;
- `RefreshIntervalPicker.tsx` — выбор интервала автоматического обновления;
- `constants.ts` — предустановки периода и интервала;
- `types.ts` — TypeScript-типы;
- `page-header.css` — стили компонента.

## Принцип работы

Шапка используется только на страницах мониторинга. На страницах управления,
поиска, аудита, консоли, настроек и профиля отображается только название страницы.

Период поддерживает:

- быстрые относительные диапазоны;
- абсолютный диапазон «От — До» с датой и временем;
- сохранение выбора в `localStorage`.

Автообновление является общим для текущей страницы. При наступлении выбранного
интервала иконка обновления кратковременно вращается, после чего запускается
зарегистрированный обработчик загрузки данных страницы.

Абсолютный диапазон добавлен как единый frontend-контракт для будущего подключения
долговременного источника исторических метрик. Текущие backend-эндпоинты могут пока
использовать только доступную оперативную историю.
