# Page Header KSC

## Назначение

`page-header` — единая горизонтальная верхняя область интерфейса Kafka System Control.

Компонент отвечает за:

- название текущей страницы;
- краткое описание страницы;
- отображение выбранного Kafka-кластера на мониторинговых страницах;
- выбор периода данных;
- выбор интервала автоматического обновления;
- ручное обновление данных;
- визуальную индикацию загрузки данных.

## Режимы

### Monitoring

Используется для страниц мониторинга:

- Обзор;
- Брокеры;
- Топики;
- Группы потребителей;
- Оповещения.

В этом режиме справа доступны период, интервал обновления и кнопка обновления.

### Default

Используется для функциональных страниц:

- Поиск сообщений;
- ACL;
- Аудит;
- Консоль;
- Настройки;
- Пользователь;
- Удаление;
- будущие страницы интеграций.

В этом режиме отображаются только название и описание страницы.

## Период

`TimeRangePicker` поддерживает относительные интервалы и абсолютный диапазон дат.

Абсолютный диапазон добавлен заранее, чтобы UI не пришлось переделывать при
подключении долговременного источника исторических метрик.

## Загрузка

Во время загрузки данных горизонтальный разделитель получает анимированную
подсветку слева направо. При автоматическом или ручном обновлении одновременно
вращается иконка обновления справа.

## Прокрутка

Общая область приложения не имеет внешнего scrollbar. Конкретные рабочие панели
должны самостоятельно включать `overflow: auto`, когда их содержимое перестаёт
помещаться в доступную высоту.
