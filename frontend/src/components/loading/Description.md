# Loading Screen

## Назначение

Данный модуль реализует профессиональный экран загрузки приложения
Kafka System Control (KSC).

Экран отображается сразу после запуска приложения и скрывается
только после полной инициализации пользовательского интерфейса.

Главная задача загрузочного экрана:

- исключить отображение белого экрана браузера;
- показать пользователю процесс запуска приложения;
- повысить визуальное качество продукта;
- отображать этапы подключения к Kafka;
- обеспечить плавный переход к интерфейсу.

# Описание файлов

## LoadingScreen.tsx

Главный компонент экрана загрузки.

Отвечает за:

- композицию всего интерфейса;
- запуск анимаций;
- отображение логотипа;
- отображение статуса;
- отображение прогресс-бара;
- плавное исчезновение экрана.

---

## LoadingLogo.tsx

Отображает логотип приложения.

Позже будет содержать:

- SVG логотип Kafka;
- градиентный текст KSC;
- анимацию появления;
- эффект приближения;
- масштабирование.

---

## LoadingProgress.tsx

Компонент прогресс-бара.

Позже будет поддерживать:

- проценты;
- плавную анимацию;
- свечение;
- градиентную заливку.

---

## LoadingStatus.tsx

Отображает текущий этап загрузки.

Например:

• Инициализация приложения...

• Загрузка темы...

• Подключение к кластеру DEV...

• Подготовка приветственной страницы...

---

## useLoading.ts

Хук управления экраном загрузки.

Отвечает за:

- прогресс;
- этап загрузки;
- скрытие экрана;
- таймеры;
- события приложения.

---

## loading.ts

Общие типы TypeScript.

Позже будут храниться:

- LoadingStage
- LoadingState
- LoadingStep
- LoadingStatus
