# Страница «Обзор»

## Назначение

Главная мониторинговая страница Kafka System Control. Показывает состояние
выбранного Kafka-кластера, ключевые KPI, распределение партиций, скорость
Producer/Consumer, сертификаты, пропускную способность, Consumer Lag и
последние события.

## Структура

Все специфичные для Overview React/TypeScript-компоненты находятся в
`src/pages/overview/components/`.

Общие элементы приложения не дублируются внутри страницы.

## Данные и безопасность контекста

При смене Kafka-кластера состояние Overview очищается. Данные нового кластера
показываются только после успешной проверки его доступности. Поэтому данные
предыдущего рабочего кластера не могут отображаться на экране выбранного
недоступного кластера.

## Полноэкранный режим

Каждая основная панель Overview имеет кнопку полноэкранного просмотра.
Режим закрывается кнопкой в том же месте или клавишей Escape.

## Исторические диапазоны

Frontend уже поддерживает относительный и абсолютный диапазон времени.
Абсолютный диапазон подготовлен для будущего подключения долговременного
источника метрик.
