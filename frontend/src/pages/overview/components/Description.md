# Компоненты Overview

Компоненты этой директории отвечают только за визуальные и локальные данные страницы «Обзор».

- `ClusterHealthPanel` — состояние кластера и брокеры.
- `CertificatesPanel` — сертификаты Kafka.
- `ThroughputPanel` — общая пропускная способность.
- `TopicsPanel` — пропускная способность по топикам.
- `ConsumerLagPanel` — группы потребителей и lag.
- `EventsPanel` — последние события.
- `PanelFullscreenButton` — центрированное увеличение панели.

Все комментарии и публичные интерфейсы компонентов должны оставаться на русском языке.
