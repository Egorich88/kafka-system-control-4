# Компоненты страницы «Обзор»

## Назначение

Каталог содержит React/TypeScript-компоненты, относящиеся только к странице
мониторинга Kafka-кластера «Обзор».

Здесь находятся:

- сводное состояние кластера и встроенные KPI;
- распределение партиций;
- Consumer / Producer rate;
- сертификаты Kafka;
- пропускная способность кластера;
- пропускная способность по топикам;
- Consumer Lag;
- последние события;
- кнопка полноэкранного просмотра панели.

## Принцип

Компоненты страницы не размещаются в глобальном `src/components`, если они
не используются другими страницами. Это сохраняет границы ответственности
и соответствует структуре крупных страниц KSC.

Стили остаются в `src/styles/overview/`, поскольку существующая тема KSC
централизует CSS в каталоге стилей.
