# Audit — Аудит

## Kafka System Control 4.2.2

Страница `Audit` предназначена для отображения истории действий пользователей и системных событий, связанных с Kafka-кластером.

Основная задача страницы:

> показать кто, когда, что и над каким объектом сделал, а также с каким результатом завершилась операция.

---

# Назначение страницы

Audit используется администраторами и операторами Kafka-кластера для:

- контроля действий пользователей;
- расследования проблем;
- поиска изменений конфигурации;
- контроля удаления и создания объектов;
- анализа активности пользователей;
- просмотра ошибок операций;
- восстановления последовательности действий;
- последующего security/audit monitoring.

---

# Архитектура страницы

Страница состоит из следующих уровней:

1. Header
2. KPI
3. Последние события
4. Analytics / Overview
5. Filters
6. Audit Log
7. Details Panel
