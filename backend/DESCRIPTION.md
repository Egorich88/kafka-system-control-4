# Backend — изменения мониторинга Overview

## Сертификаты Kafka

Добавлен `certificates.go` и API:

`GET /api/overview/certificates`

Endpoint ищет JKS/PKCS12/PFX хранилища в стандартных Linux-каталогах,
по переменным `KAFKA_SSL_*_LOCATION`, а также внутри Kafka-контейнера Docker,
если backend имеет доступ к Docker.

## Версия Kafka

Получение версии брокера дополнено штатной командой:

`kafka-topics.sh --version`

Поддерживаются Docker и стандартные пути Linux. Если команда недоступна,
сохраняются резервные способы через логи и JAR.

Версия не хранится единым глобальным значением между кластерами, чтобы
при переключении Kafka-кластера не показать версию другого окружения.

## Доступность кластера

Frontend сначала выполняет проверку `/api/overview/health`. Если выбранный
кластер недоступен, данные предыдущего кластера не используются.
